# Contributing Guidelines

## Branch Strategy

- `main` branch contains stable and reviewed code.
- `develop` branch is used for ongoing development.
- Feature branches are created from the `develop` branch.

## Contribution Steps

1. Create a new feature branch from `develop`.
2. Make your changes and commit them with meaningful commit messages.
3. Open a Pull Request targeting the `develop` branch.
4. At least one team member reviews the Pull Request.
5. Apply feedback if needed and merge the changes.

## Code Style

- Follow basic C++ and Docker file conventions used in the project.
- Try to keep commits small and related to a single task.
